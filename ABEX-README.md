# ABEX Pumps Website

A modern, professional website for ABEX Pumps - a trusted supplier of water pumps, submersible pumps, and industrial pump systems.

## Website Structure

The website consists of 5 main pages:

1. **Home Page** (`abex-index.html`)
   - Full-width hero image with powerful water pump
   - Headline: "Reliable Water Pump Solutions for Every Industry"
   - Subheadline: "Quality You Can Trust – ABEX x Paragon Pump"
   - Image gallery showing pumps and applications
   - Paragon Pump highlight section
   - Call-to-action: "Explore Products"

2. **About Us Page** (`abex-about.html`)
   - Header photo of factory or pump warehouse
   - Company background and history
   - Mission & values (reliability, efficiency, customer support)
   - "Why Choose ABEX?" section with icons and visuals

3. **Products Page** (`abex-products.html`)
   - Visual grid of product cards (image, product name, short specs)
   - Product categories:
     - Water Pumps
     - Submersible Pumps
     - Industrial Pumps
     - Accessories
   - Big image banners between categories
   - Paragon Pump featured section

4. **Our Projects Page** (`abex-projects.html`)
   - Showcase of real-world installations and completed projects
   - Project cards with image, title, and description
   - Full-width photo banner between sections
   - Project highlights section

5. **Contact Us Page** (`abex-contact.html`)
   - Background image of factory, pipe system, or water flow
   - Contact form (Name, Email, Phone, Message)
   - Company contact details
   - Google Map placeholder
   - Call-to-action: "Get a Quote"

## Design Features

- Professional industrial look using blue, silver, and white color palette
- High-quality photos with rounded corners and soft shadows
- Smooth fade-in animations on scroll using AOS library
- Fully responsive design for desktop, tablet, and mobile
- Modern typography with Montserrat and Open Sans fonts
- Subtle motion effects for banners

## Technical Implementation

- HTML5 semantic structure
- CSS3 with Flexbox and Grid layouts
- Responsive design with media queries
- AOS (Animate On Scroll) library for animations
- Feather Icons for iconography
- Vanilla JavaScript for interactivity

## How to View the Website

1. Open any of the HTML files directly in a web browser:
   - `abex-index.html` (Home Page)
   - `abex-about.html` (About Us Page)
   - `abex-products.html` (Products Page)
   - `abex-projects.html` (Our Projects Page)
   - `abex-contact.html` (Contact Us Page)

## Customization

To customize the website:

1. **Content**: Edit the HTML files directly to change text content
2. **Images**: Replace the Unsplash image URLs with your own image URLs
3. **Colors**: Modify the CSS variables in `assets/css/abex.css`
4. **Fonts**: Update the Google Fonts links in the HTML `<head>` section
